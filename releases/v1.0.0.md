# naluz/framework v1.0.0 — first release

The first stable release of the **NaluzPHP framework core**: a modern, secure PHP 8.2+ framework for monolithic apps and
REST APIs, with a built-in ORM and an independent query builder. Applications install it with Composer; the
[application skeleton](https://github.com/taliffsss/framework) is the easiest way to start.

```bash
composer require naluz/framework
```

## What's included

- **HTTP:** PSR-7/15 pipeline, router with groups, middleware and route caching, CORS, rate limiting, security headers.
- **Database:** query builder + active-record ORM (relations incl. polymorphic and has-many-through, eager loading, soft
  deletes, casts, events, factories, seeders), schema builder and migrations, lazy-load (N+1) guard. Drivers: SQLite,
  MySQL/MariaDB, PostgreSQL, **SQL Server**.
- **Read/write splitting:** separate primary/replica sessions, replica pools, sticky reads, failover, read-only
  replicas, `useWritePdo()`.
- **NoSQL:** `file`, `memory` and **MongoDB** document stores with an injection-safe query builder.
- **Model caching:** opt-in (`MODEL_CACHING=true`, Redis or local), 5-minute default TTL, automatic invalidation and
  re-caching on writes, transaction-safe, falls back to the database if the cache store fails.
- **Queues** (sync/database/Redis), **mail** (SMTP/log/array), **scheduler**, **file storage**, dependency-free
  **Redis** client.
- **Templates:** compiled, auto-escaping engine (`*.naluz.php`).
- **Security:** Argon2id, encryption, JWT, CSRF, sessions, validation, SSRF-guarded HTTP client.
- **Logging:** PSR-3 channels (daily, single, stderr, error_log, Slack, stack, custom).
- **CLI:** `php naluz` with `run:server --port=8001`, migrations, seeding, queue, scheduler and cache commands.
- **Standards:** PSR-1, 3, 4, 6, 7, 11, 12, 13, 14, 15, 16, 17, 18 (Guzzle) and 20.

## Verification

The test suite (698 tests) lives in the application skeleton and runs in CI on PHP 8.2, 8.3, 8.4 and 8.5, with the
PSR-12 coding standard enforced.

## Known limitations

- SQL Server support is verified by SQL-generation tests only (no live SQL Server in CI); needs `pdo_sqlsrv`.
- The MongoDB adapter is tested against a fake collection, not a live server (needs `mongodb/mongodb` + `ext-mongodb`).
- MySQL and PostgreSQL grammars are verified by SQL-generation tests; integration tests run on SQLite and a real Redis.
- Rate limiting is a fixed window.

## Requirements

PHP 8.2+, `ext-pdo`, `ext-mbstring`, `ext-openssl`, `ext-sodium`, `ext-fileinfo`.
