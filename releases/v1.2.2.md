# naluz/framework v1.2.2 — clean release of GraphQL and model observers

This release contains the code intended for 1.2.0 (the built-in GraphQL server and model observers) and fixes the version string.

## What happened to 1.2.0 and 1.2.1

Both tags were first seen by Packagist while they pointed at an earlier commit (model observers only, without GraphQL). The tags were
later corrected on GitHub, but Packagist kept serving the earlier commit, so `composer require naluz/framework:^1.2` installed a
framework **without** the GraphQL classes. **Do not use 1.2.0 or 1.2.1 on Packagist.** 1.2.2 is created once, at the right commit.

## Changes

- `Application::VERSION` is now `1.2.2` (it still said `1.0.0`, so `php naluz list` printed the wrong version).
- No other code changes. See [v1.2.0](v1.2.0.md) for the feature list.

## Upgrading

```bash
composer require naluz/framework:^1.2.2
```
