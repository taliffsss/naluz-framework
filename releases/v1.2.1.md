# naluz/framework v1.2.1 — packaging fix

This release contains the same code as the intended **1.2.0**: the built-in GraphQL server and model observers.

## Why 1.2.1

The `v1.2.0` tag was published on Packagist when it pointed at an earlier commit (model observers only), and was later
re-pointed to the commit that adds GraphQL. Packagist kept the earlier commit, so `composer require naluz/framework:^1.2` could
install a 1.2.0 **without** the GraphQL classes. Tags should never move after publication, so this is a new, immutable release.

## Upgrading

```bash
composer require naluz/framework:^1.2.1
```

Applications that use GraphQL must require `^1.2.1` (not `^1.2.0`). There are no code changes compared with the GraphQL
commit (`73d4fa9`) that the 1.2.0 notes describe; see [v1.2.0](v1.2.0.md) for the feature list.
